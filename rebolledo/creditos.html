Créditos del Proyecto

Autoría y Desarrollo

Este sistema web educativo fue diseñado, estructurado y programado como una herramienta interactiva para el aprendizaje colaborativo de la geometría analítica.

Desarrollador: @Brandon Ryan Zea Martinez

Propósito: Facilitar la comprensión paso a paso de conceptos matemáticos fundamentales, permitiendo la creación de una comunidad de estudio donde los estudiantes puedan compartir sus propios ejercicios resueltos.

Tecnologías y Herramientas

Para la construcción completa de esta plataforma web se emplearon tecnologías estándar de la industria del desarrollo de software:

  • HTML5 & CSS3: Arquitectura estructural y diseño responsivo basado en interfaces translúcidas (Glassmorphism).
  • JavaScript (ES6): Control dinámico de las ventanas modales, lógica de los ojos de las contraseñas, evaluación interactiva del quiz y conexiones asíncronas vía Fetch API.
  • PHP 8: Procesamiento seguro del backend, validación de sesiones activas, encriptación Bcrypt para contraseñas y gestión de subida de archivos multimedia.
  • MySQL: Almacenamiento e indexación relacional de los usuarios registrados y el registro de imágenes compartidas por la comunidad.
  • XAMPP (Apache Server): Entorno de servidor local integrado y gestión de base de datos a través de phpMyAdmin.
  • Inteligencia Artificial (IA): Utilizada como soporte técnico avanzado para comprender nuevas etiquetas HTML, estructurar la lógica de bases de datos y agilizar la identificación y corrección de errores de código.
